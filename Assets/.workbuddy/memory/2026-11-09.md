- 循环根因：WordPracticeSession.AdvanceWord 仅 mode==2 结束，建 session 传 randomOrder?1:0 → 无限循环。两处调用点（InitOnline/InitLocalSession）改传 2（一轮即止）。randomOrder 开关保留：true 时 ShuffleList（Fisher-Yates，seed=TickCount）打乱顺序，仍只一轮，tooltip 同步更新。
- 注意教训：用 node 批量替换时注释插在语句 ; 之前会吞分号导致编译错误，已修复并把注释移到语句上方。
