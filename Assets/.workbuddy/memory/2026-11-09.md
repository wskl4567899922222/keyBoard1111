## 音节拆分"没打完就全读"修复（11:51，用户反馈：拆分模式打完字母应只读音节音标，但现在有时没打完就读整词）
- 数据排查：WordSyllableMap.json 163 词中仅 battery 段数不匹配（kept 段[bat,te] vs 音节[bat,te,ry]）；split mp3 结构 = [整词(s=0), 音节1..N, 整词]——**从 0 播就是整词发音**。
- 根因：① PlaySplitSegment 在 Play 前设 AudioSource.time，WebGL 上偶发被重置 → 从 0 播出整词（"没打完就全读"）；② 完词脉冲 OnWordPulseStarted 播 word_en 整词音，拆分模式下打完最后一个音节后又叠一遍整词；③ battery 类按序号取段错位。
- 修复（WordTrailTyping.cs 四处）：
  1. PlaySplitSegment 改 Play 之后再设 time + 新增 splitSeekTarget/splitSeekUntil，Update 里 0.5s 窗口校正（time 掉回片段起点前 0.08s 以上就重新 seek）；
  2. OnWordPulseStarted 加门：SyllableSplitEnabled 且多音节词 → 跳过整词发音；
  3. PlayPhonemeFor 拆分分支改按音节文本匹配分段，失败退回序号；
  4. 兼容并行会话新加的 PlayVoice/voiceWarmed 预热逻辑（整词音走 PlayVoice，split 片段因需 time/Stop 控制仍走 splitSource 直播）。
- 待用户 Build 验证。
