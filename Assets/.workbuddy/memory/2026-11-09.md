## 音节拆分双色 + 圆点分隔（单词文本）
- 需求：开启"单词拆分"模式时，3D 单词文本只按音节交替两色（深藏蓝 #1E3A5F / 橙 #F59E1B，取自 cos·tume 截图），音节间画小圆点分隔。
- 实现：
  - TrailWordBatch 增加 SetColor(index,color)（运行时改色不打乱索引）。
  - KeyboardSingleTrail：SyllableColorA/B 静态色、ApplySyllableSplit(List<int> starts)/ClearSyllableSplit()、程序生成圆点 Sprite（SyllableDotSprite，抗锯齿），圆点是纯装饰 SpriteRenderer 挂 word root，不进 TrailWordBatch → 打字/下划线/音标索引不受影响；SetLetterColor 同步 model 色（等待态/飞行/命中特效唯一色源）+ Appearance.SetMainColor + 等待态低不透明度。
  - PrepareWord 增加可选 syllableStarts 参数（新词生成时直接上双色）。
  - WordTrailTyping：CurrentSyllableStarts()（SyllableSplitEnabled + syllableByWord 多音节 + 长度对齐校验）；PrepareCurrentWord 传入；RebuildPhonicsOverlay 里 ApplyWordSyllableColors() → 词中途切模式立即换色。
- 还原路径：退出拆分模式 → PhonicsColors.PerLetter 恢复拼读色并删圆点。
